# CS3090-Password-Strength-Checker

    This Program simply takes in input from the user, a name and password, and checks for any errors that may deem the password unsafe. Requirements of a good password in this programa are the following: at least 10 characters, at least one special character, no spaces, and it can not contain the user's name within. The result will be printed to the console.
    To run this program, you use the provided Makefile calls to compile and begin. It has no other dependencies besides the main file. This tool is for educational use only and does not present valid security precautions. It utilizes a simple line of if else statements to check if the password provided fits my own criteria. 
    One possible limitation of this is the oversimplified criteria. It may label a password as strong even if it is predictable (ex. Password123!), which may or may not make it vulnerable to dictionary attacks or common pattern guessing. One other consideration of this is malicious modicfication: someone could potentially modify it to collect and store passwords secretly. If shared publicly, it could manifest into a phishing or credential-harvesting tool, for instance.
    Furthermore, the password is stored temporarily through a private variable in an object, creating a privacy risk. If this is modified or expanded for any other use, some responisble guidleines would be not to store plaintext passwords, not to transmit them anywhere, and definately hash inputs immediately to avoid persistence. 
    Once again, this was created for educational purposes; it simply provides a basic evaluation of password strength based on length and character variety. It does not guarentee security against all attacks.
